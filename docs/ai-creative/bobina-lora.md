# Bobina LoRA

Create your own high-quality Bobinas using our official LoRA model on HuggingFace.

For advanced AI artists, we have released our official Bobina LoRA (Low-Rank Adaptation) model on [HuggingFace](https://huggingface.co/bobinamoe/bobinas). This allows you to generate Bobinas with incredible detail and style consistency using tools like ComfyUI.

### How to use in ComfyUI

1. Download the LoRA file from our HuggingFace page.
2. Place the file in your `ComfyUI/models/loras` directory.
3. In your ComfyUI workflow, add a "Load LoRA" node and select the Bobina LoRA file.
4. In your positive prompt, include the trigger word `Bobina`.
5. Experiment with different weights (e.g., 0.7 to 1.0) and descriptive tags to create your perfect Bobina!
